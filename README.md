# Relay

Team chat that picks the best OpenRouter model for each task, with web search, document chat, code execution and connectors.

Start here:

1. `docs/SPEC.md`: what we're building and why
2. `CLAUDE.md`: rules Claude Code follows in this repo
3. `docs/TASKS.md`: the build, phase by phase

To begin: open this folder in Claude Code, run the one-time MCP setup command from `CLAUDE.md`, then paste the Phase 0 prompt from `docs/TASKS.md` in plan mode.
